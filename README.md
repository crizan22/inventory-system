# Inventory System

A simple full-stack app to add, edit, and delete stock items. Items with a quantity of 5 or less are highlighted in red, and the total stock value is calculated automatically.

## Tech stack
- React (Vite)
- Node.js + Express
- SQLite (better-sqlite3)

## How to run

Backend:
```
cd server
npm install
node server.js
```

Frontend (in a second terminal):
```
cd client
npm install
npm run dev
```

Then open http://localhost:5173
